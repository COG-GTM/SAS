# SAS program and dataset catalog

Inventory of every program in `Example code/` and every dataset/file it touches.
Generated by `generate_catalog.py` (Python 3.11+, standard library only):

```bash
python3 python/catalog/generate_catalog.py          # rewrite programs.csv / datasets.csv
python3 python/catalog/generate_catalog.py --check  # exit 1 if the CSVs are stale
pytest python/catalog                               # parser + catalog tests
```

The generator is a static scanner (no SAS runtime): it blanks comments and
DATALINES/CARDS data, splits statements and records the ones that read or write data.

## programs.csv — one row per program

| column | meaning |
| --- | --- |
| `key` | unique id: `ed2:<ch>-<n>` (Programs Used in the Second Edition), `sol:<ch>-<n>` (odd-numbered solutions), `cd:cd-NN` (one block of `Create_Datasets.sas`) |
| `program_id` | tag as used in the book (`3-1`); `cd-NN` for Create_Datasets blocks |
| `source_file`, `chapter`, `tag`, `start_line`, `end_line` | location; `tag` is the raw comment (`*3-1;`) or the Create_Datasets header text |
| `has_code` | 0 when the block is comment-only (written answers, commented-out "Demonstration Program"s) |
| `datasets_read` / `datasets_written` | every dataset referenced (`learn.x`, `sashelp.x`, WORK datasets unqualified) |
| `datasets_required` | datasets read before the program writes them, i.e. its inputs from other programs |
| `files_read` / `files_written` | external files; inputs resolved case-insensitively to `Data/<file>` |
| `procs` | PROCs in order of first use |
| `macro`, `proc_sql`, `prx`, `arrays`, `retain_by`, `ods`, `sgplot`, `user_formats`, `inline_data` | 1/0 feature flags (see below) |
| `notes` | irregular tags, filename case mismatches, libref aliases, dynamic names |

Lists use `;` as separator. Flags: `macro` = `%macro/%let/&var/call symput`;
`retain_by` = RETAIN, DATA-step BY, `first./last.` or sum statement; `sgplot` = any
`PROC SG*`; `user_formats` = PROC FORMAT in the program or use of a format defined
by any PROC FORMAT earlier in the sources (Create_Datasets formats are stored in Learn);
`inline_data` = DATALINES/CARDS.

LIBREFs pointing at the Learn folder (`perm`, `mozart`, `proj99`) are catalogued as `learn.*`.

## datasets.csv — producers and consumers

One row per `learn.*` dataset, WORK dataset built by `Create_Datasets.sas` and used
elsewhere (`work_shared`), `sashelp.*` table, Excel worksheet read through a LIBNAME
engine, and every file in `Data/`. `producers` are programs that write it, `consumers`
are programs listing it in `datasets_required` / `files_read`.
